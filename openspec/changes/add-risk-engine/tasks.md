# Tasks

Owner pause points (commit-and-pause policy): every group below touches the gate, risk rules, order paths, a broker adapter, the kill switch, a migration or `docs/DECISIONS.md`, so pause for the owner's review with the reviewer's report after **every group**, and again when all tasks are done, before archiving.

Convention: "scenario" means the `#### Scenario:` of the named spec in `specs/`. Every task's verify step runs through `uv run pytest` unless stated, and every group ends with format, lint, mypy and `lint-imports` clean.
